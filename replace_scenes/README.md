# Замена сцен игры

Положи сюда карту — и она заменит сцену игры с таким же именем. Имя файла = имя сцены.

- `hub.glb` — заменит хаб (3D-модель; из неё делается пол/стены с коллизией, текстура берётся из модели).
- `hub.map` — то же, но своя карта из редактора (текст «Скопировать карту»).
- `hub.json` (необязательно) — настройки: `{"spawn":[0,2,0],"sky":"87B8E8","scale":1}`.

Имена сцен игры: `hub`, `backrooms`, `hive`, `level_1`, `level_2`, `level_3`, `level_4`
(служебные `splash_screen`, `intro`, `save_select` не заменяй — это заставка и выбор сохранения).
Другие имена можно подсмотреть в редакторе карт (кнопка «Сцена») или в логе игры: «сцена: … → «имя»».

Файл убрал из папки — замена пропадает. Карта появляется в списке как «Замена: …», её можно выключить переключателем.
