# Bearite

Лаунчер и загрузчик модов для **Super Bear Adventure** (Android, Unity IL2CPP) в духе Geode.
Игра **не удаляется и не перепаковывается**: Bearite — отдельное приложение, которое берёт
установленную из магазина игру, запускает её `UnityPlayer` в своём процессе и подгружает моды.

## Что умеет
- **Запуск игры с модами** без изменения оригинала.
- **Вкладки Игра / Моды / Лог** (Material Design 3): статус игры, включение, удаление и настройка модов, лог.
- **Мод-меню внутри игры** в стиле самой игры: на паузе появляется кнопка «Моды», панель с вкладками «Установлено» / «Все моды», у каждого мода шестерёнка с настройками.
- **Аватарки модов**: если в папке мода лежит `icon.png`, он показывается в списке и в мод-меню.
- **Настройки модов**: переключатели, слайдеры, числа, строки, выпадающие списки. Описываются в `mod.json`.
- **Нативные моды (`.so`)** с SDK: чтение настроек, хуки (Dobby), доступ к IL2CPP.
- **AssetBundle-моды**: загрузка бандлов в игру.

## Как это работает
1. `GameActivity` собирает `PathClassLoader` из APK игры (и split-APK) + нашего APK.
2. Подменяет игре `Context` (имя пакета, ресурсы, assets, путь к APK), системе отдаёт свои.
3. Создаёт плеер Unity: `UnityPlayerForActivityOrService` (Unity 6) или `UnityPlayer(Context)` (старые версии).
4. `libbearite.so` ждёт IL2CPP (10 с после загрузки), подключает свой поток, загружает бандлы и нативные
   библиотеки включённых модов, затем следит за `Time.timeScale`: ноль = пауза, и Java показывает кнопку «Моды».
5. Игра идёт в процессе `:game`; при выходе он убивается, лаунчер и оригинал остаются как были.

## Сборка
APK собирает GitHub Actions (`.github/workflows/build.yml`): вкладка Actions → артефакты
`Bearite-debug` (APK) и `example-mod-hello-native` (пример мода, zip).
Локально: NDK 26, `bash scripts/build_dobby.sh`, затем `gradle :app:assembleDebug`.

## Формат мода
Zip с `mod.json` в корне (или в единственной папке). Ставится кнопкой «Установить мод» или кладётся в
`Android/data/com.bearite.patcher/files/mods/<id>/`.

```json
{
  "id": "my-mod", "name": "Мой мод", "version": "1.0", "author": "я",
  "description": "Что делает мод",
  "bundles":  [ { "src": "maps/arena.bundle" } ],
  "libs":     [ "libs/arm64-v8a/libmymod.so" ],
  "settings": [
    { "id": "god",   "type": "bool",   "name": "Бессмертие", "default": false },
    { "id": "speed", "type": "float",  "name": "Скорость", "min": 0.5, "max": 3, "default": 1 },
    { "id": "lives", "type": "int",    "name": "Жизней", "min": 1, "max": 9, "default": 3 },
    { "id": "nick",  "type": "string", "name": "Ник", "default": "Bear" },
    { "id": "mode",  "type": "choice", "name": "Режим", "options": ["лёгкий", "обычный"], "default": "обычный" }
  ]
}
```

Типы настроек: `bool`, `int`, `float`, `string`, `choice`. У `int`/`float` с `min` и `max` рисуется слайдер,
без диапазона — поле ввода. Значения хранятся в `<мод>/settings.json` и сохраняются при обновлении мода.

**Безопасность.** Моды с `libs` выполняют нативный код внутри игры. Они выключены по умолчанию,
при первом включении Bearite просит подтверждение; после переустановки мода подтверждение нужно снова.
Включай только те моды, которым доверяешь.

## SDK нативных модов
Заголовок `sdk/bearite_api.h`, пример `sdk/example-mod/` (C, собирается в CI). Мод экспортирует

```c
void bearite_mod_init(const BeariteApi* api, const char* mod_id);
```

и получает через `api`: `log`, `il2cpp_symbol`, `module_base`, `hook`, `get_bool/int/float/string`.
Настройки перечитываются при изменении, так что мод может опрашивать их в любой момент.

## Что не проверено на устройстве
Код собирается и компилируется (нативная часть и пример — в CI, плюс проверка на хосте), но запуск
на телефоне с настоящей игрой пока подтверждён только до создания `UnityPlayer`. Не проверено вживую:
- создание плеера Unity 6 и ввод (касания, клавиши) через `injectEvent`;
- хук `il2cpp_runtime_invoke`, `AssetBundle.LoadFromFile`, `dlopen` нативных модов;
- кнопка «Моды» поверх игры и возврат из меню;
- проверки целостности и Google Play (лицензия, покупки) в самой игре.

Если что-то не заработает, смотри вкладку «Лог»: туда пишут и лаунчер, и нативная часть.

## Ограничения
- Сохранения запуска через Bearite лежат в данных Bearite и **отдельно** от оригинальной игры.
- Включение и выключение модов, а также нативный код применяются после перезапуска игры.
- Создание карт из ассетов игры (расстановка префабов) пока не реализовано.
- Только arm64-v8a.
