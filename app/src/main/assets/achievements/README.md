# Достижения Bearite

Сюда добавляются встроенные достижения.

1. Допиши запись в `index.json`: `{"id":"my_id","name":"Название","desc":"Как получить","icon":"my_id.png"}`.
2. Положи рядом аватарку `my_id.png` (квадрат, лучше 256×256). Нет файла — покажется ★.
3. Открывает достижение код: лаунчер `AchievementStore.unlockKey("bearite:my_id")`, игра — строка `bearite<TAB>my_id` в `filesDir/_ach`.

Анимация получения (позже): будет показываться при открытии, файл положим сюда же.
