# Готовые моды для каталога

Сюда кладём готовые zip-архивы модов (без исходников), которые должны попасть во вкладку «Все моды».
Сейчас сборка (`.github/workflows/build.yml`) эти файлы никуда не публикует: zip лежат здесь как хранилище.
Чтобы мод попал в «Все моды», его нужно вручную добавить в релиз `mods` на GitHub вместе с записью в `index.json`.

Чтобы добавить мод сюда: положить zip (в корне архива должны быть `mod.json` и `libs/arm64-v8a/…`) и закоммитить в `main`.
