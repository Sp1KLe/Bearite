# Готовые моды для каталога

Сюда кладём готовые zip-архивы модов (без исходников), которые должны попасть во вкладку «Все моды».
Сборка (`.github/workflows/build.yml`, шаг «Publish mods catalog») копирует все `mods-prebuilt/*.zip` в каталог
вместе с собранными модами, и они появляются в index.json релиза `mods`.

Чтобы добавить мод: положить zip сюда (в корне архива должны быть `mod.json` и `libs/arm64-v8a/…`), закоммитить в `main`.
